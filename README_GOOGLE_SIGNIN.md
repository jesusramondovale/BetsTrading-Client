# 🔐 Configuración de Google Sign-In - Resumen

## 📖 Documentación Disponible

Este proyecto contiene documentación completa sobre la configuración de Google Sign-In:

1. **`CONFIGURACION_GOOGLE_SIGNIN.md`** ⭐ - **LEE ESTE PRIMERO**
   - Guía completa y detallada
   - Explica la diferencia entre PCs (trabajo/casa)
   - Workflow recomendado

2. **`TUS_HUELLAS_SHA.txt`**
   - Huellas SHA del PC del TRABAJO (actuales)
   - Instrucciones rápidas para agregarlas

3. **`OBTENER_SHA.md`**
   - Métodos para obtener huellas SHA
   - Comandos detallados

4. **`UBICACION_KEYSTORES.md`**
   - Información sobre ubicación de keystores
   - Cómo crear/buscar keystores

## ⚠️ Punto Clave: Configuración por PC

**Las huellas SHA son ÚNICAS por cada PC.**

- ✅ PC del TRABAJO: Tiene sus propias huellas SHA
- ✅ PC de CASA: Tendrá DIFERENTES huellas SHA
- ✅ Ambas deben estar agregadas en Google Cloud Console

## 🚀 Inicio Rápido

1. Lee `CONFIGURACION_GOOGLE_SIGNIN.md` para entender el contexto completo
2. Si estás en el PC del TRABAJO: Las huellas ya están en `TUS_HUELLAS_SHA.txt`
3. Si estás en el PC de CASA: Usa `OBTENER_SHA.md` para obtener tus huellas
4. Agrega TODAS las huellas SHA en Google Cloud Console
